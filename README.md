# 🎬 Movieverse — Movie Collection Platform

**Movieverse** is a full-stack web application for exploring and managing a large collection of movies. Users can filter by genre, view detailed information, post and read reviews in real-time, and discover top movies efficiently.

---

## 🛠️ Technologies Used

**Backend:**
- Node.js
- Express.js
- MongoDB
- Mongoose

**Frontend:**
- React
- Vite
- Tailwind

**Authentication & Security:**
- JWT-based sessions
- Role-based access control
- Protected routes

**Data Handling:**
- MongoDB Aggregation Pipelines
- Custom Middleware

**Real-time & Media:**
- Live review updates

**Utilities:**
- Logging
- Environment configuration

---

## 🚀 Features

- 🔍 **Explore 1,000+ Movies**  
  Browse and search movies by genre, title, or keyword with intuitive filters.

- ⚡ **Efficient Data Fetching**  
  Uses optimized MongoDB aggregation to fetch top movies per genre with minimal server load.

- 💬 **Real-time Reviews**  
  Logged-in users can post and view reviews instantly, fostering dynamic discussions.

- 🔐 **Secure Authentication**  
  JWT-based login system with role-based access ensures protected user interactions.

- 🧱 **Scalable Backend Architecture**  
  Built with production-ready logging, error handling, and modular route design.
